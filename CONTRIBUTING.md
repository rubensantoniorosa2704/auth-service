# Contributing

Thank you for your interest in contributing to this project!

This repository is primarily a portfolio project, but suggestions,
improvements, and fixes are welcome.

## 🧭 Guidelines

- Follow Go best practices and idiomatic code
- Keep the code simple and readable
- Write unit tests for new features
- Keep commits small and meaningful
- Use clear commit messages in English

## 🧪 Tests

Before opening a pull request, make sure all tests pass:

```
go test ./internal/...
```

## 📝 Commit Messages

Use conventional commit style when possible:

- feat: new feature
- fix: bug fix
- test: adding or updating tests
- chore: maintenance or setup

Example:

```
feat(core): add user registration use case
```

## 📬 Pull Requests

1. Fork the repository
2. Create a new branch from `main`
3. Make your changes
4. Open a pull request with a clear description

Thank you!
